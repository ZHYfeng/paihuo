# 前端工作空间设计

本设计对应 2026-10 的前端重设计。整体采用用户确认的方向：**暖灰画布、白色面板、石墨色侧栏**，以蓝色强调操作，用清晰的信息层级支持长时间工作。

领域术语与实体边界遵循根目录 `CONTEXT.md`。本文件只描述页面布局、展示规则和组件约定。

## 视觉规则

- 默认使用浅色主题；保留用户已经保存的明暗偏好，切换结果保存在浏览器中。
- 品牌色 `#5663d9` 用于主操作、导航选中态与可交互强调。状态分别使用绿色、琥珀色、红色，同时保留文字说明。
- 画布 `#f6f6f3`、面板 `#ffffff`、边线 `#e5e6e1`、正文 `#25282c`、辅助文字 `#6b7176`。深色主题使用中性的石墨色阶。
- 页标题 28px，正文与操作 12–14px，统计数字 33px。辅助文字使用较低强调，不与任务标题竞争。
- 面板圆角 12px，控件圆角 8px，以留白、分隔线和轻阴影组织内容。
- Inter 字体继续自托管，中文使用系统字体。图标使用现有 Lucide，登录页使用内联 SVG，无额外外部图片或字体依赖。

## 页面框架

桌面使用 232px 固定侧栏、65px 顶栏和自适应内容区。侧栏按使用目的分组：

| 分组 | 页面 |
| --- | --- |
| 工作空间 | 工作台、项目、任务、审批 |
| 协作与自动化 | 会话、工作流、定时、历史 |
| 资源管理 | 运行环境、角色、技能、模板 |

设置与实时连接状态放在侧栏底部。顶栏包含当前位置、全局搜索、主题切换和审批入口。审批入口与侧栏显示真实待审批数量。

在 1024px 以下，侧栏改为抽屉导航；抽屉使用 Radix Dialog，支持焦点约束、Escape 关闭以及关闭后归还焦点。页面保留“跳到主要内容”入口与键盘焦点样式。

## 工作台

工作台围绕“正在做什么、哪里需要处理、项目进展如何”组织：

1. **概览**：执行队列、待你审批、今日完成、完成率。点击进入相应页面。
2. **执行队列**：全部 / 执行中 / 排队中切换；展示任务、项目、角色、创建时间与状态。首页最多展示五项，完整列表在任务页。
3. **需要你关注**：待审批总数、最近两项交付与审批入口。审批与驳回操作在审批页或任务详情完成。
4. **最近交付**：近十四天实际完成数、每日柱状图与最近四项终态任务。
5. **活跃项目**：按活跃任务数排序，展示最多四个项目及其真实完成进度。
6. **运行环境**：安装、登录情况与启用角色数。

手机端采用单列布局和两列概览；存在待审批交付时，“需要你关注”排到任务队列之前。页面空态提供下一步入口，读取失败保留错误提示和重试路径。

统计口径：

- 工作台任务队列、交付与项目进度只计入 `type=task` 且无 `cron` 的可执行任务。
- 执行队列包括 queued / claimed / running，与待审批数量分开。
- 完成率继续使用后端口径，即 succeeded / 全部可执行任务。
- 每日完成数与后端一致，按 UTC 日期读取；当天没有记录时为零，不能沿用最近一天的记录。
- 趋势图补齐最近十四天的零值日期，不生成示意趋势或虚构增长率。

## 任务、项目与审批

任务看板以浅灰列底承载白色任务卡。筛选与视图切换位于独立工具条，实现任务与代码合并分区。空看板保留流程列，在局部容器横向滚动。

项目卡包含项目图标、名称、状态、说明、交付进度和明确的项目入口。编辑、删除按钮与项目链接并列，避免交互控件嵌套。

审批页使用交付列表与流程提示的双栏布局；手机端自然堆叠。审批行为继续走原有 API、revision 与任务状态转换。

其他列表、详情、表单和对话框通过共享主题、PageHeader、Card、Button、Field、Badge、Empty 统一外观。页面介绍用用户能理解的操作说明，具体执行规则放在相关字段提示中。

## 全局搜索

顶栏按钮或 `⌘/Ctrl K` 打开搜索，匹配页面名称、项目名称、任务标题和任务编号。结果使用真实 API 数据，支持方向键选择、Enter 打开与 Tab 访问；Escape 关闭。

搜索只在打开时读取任务与项目，复用 React Query 缓存。Session、Workflow 与定时定义按各自页面跳转。对话框打开时，任务新建快捷键不再抢占输入或结果操作。

## 登录页

登录页使用石墨品牌区与暖灰表单区。品牌区呈现“项目 → 任务 → 执行 → 审批”的工作主线；表单区集中完成令牌验证。保留后端表单提交与错误提示，手机端上下排列。

## 验证方式

- `npm run typecheck`、`npm run lint`、`npm test`、`npm run build:frontend`。
- 统计回归覆盖 UTC 跨日、当天无完成记录，以及执行队列与审批分开计数。
- `scripts/e2e.sh` 覆盖桌面和 390px 手机下的主路由、全局搜索跳转、主题持久化、移动导航、任务弹窗和 API 并发契约。
- 在隔离数据库的预览实例中检查空态；浏览器仅对读取接口注入示例数据检查有任务状态，不向实际工作空间写入演示任务。
